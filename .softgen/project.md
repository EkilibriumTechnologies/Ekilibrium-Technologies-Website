# Ekilibrium Technologies

## Vision
B2B rental technology company website for Ekilibrium Technologies, specializing in software, automation, AI, and integrations for independent vehicle rental businesses (5-100+ vehicles). Target: small to mid-size operators running car, Jeep, exotic, van, golf cart, ATV rentals.

## Design
Enterprise fleet operations aesthetic — vertical SaaS precision, not generic startup.

**Colors:**
- `--primary: 220 25% 25%` (deep slate)
- `--accent: 190 60% 45%` (precision teal)
- `--muted: 220 15% 92%` (cool gray)
- `--background: 40 20% 97%` (warm white)
- `--foreground: 220 25% 15%` (near black)

**Typography:**
- Headings: Sora (600, 700) — technical authority
- Body: IBM Plex Sans (400, 500, 600)
- Mono: IBM Plex Mono (400, 500) — for operational UI

**Style direction:** Enterprise software quality. Fleet management precision. Fintech-level execution. Structured operational layouts, timeline workflows, status cards. High-contrast UI mockups showing real rental operations. Thin borders, minimal shadows, generous whitespace. Product-focused over decoration.

## Features
Multi-section homepage: Hero with rental ops UI → Rental Operations → Journey Timeline → Solutions → Street Rental product → AI for Rentals → Automation → Integrations → Case Study (Jeep Adventures PR) → Why Ekilibrium → About/Founder → Lead Form → FAQ → Footer. Mobile responsive, clean code for GitHub export, portable form architecture.
